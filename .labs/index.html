air

experimental

Wi-Fi 802.11 frame injector & PMF/WPA3 resilience auditor

Interactive Python CLI for authorized 802.11 deauthentication testing. Switches the wireless adapter into monitor mode (airmon-ng / iw), discovers APs and connected clients, and loops deauth frames with configurable reason codes. Use it to verify whether your WPA3 / PMF deployment actually protects management frames.

Quick install

git clone https://github.com/Inpriv/labs.git
cd labs/tools/air
sudo ./install.sh
sudo python air.py -i wlan0

Requirements

  • Linux
  • monitor-mode-capable adapter
  • Scapy
  • airmon-ng

Source Docs Open air.inpriv.xyz

Authorized use only. Deauthentication against networks you do not own or have explicit written permission to test is illegal in most jurisdictions.

ship-battle

experimental

2D space shooter running entirely in your browser

Ship Battle is an endless-wave arcade shooter built as a single self-contained HTML file. Pilot a defender ship, dodge incoming fire, collect power-ups (rapid fire, spread shot, shield), and survive as many waves as you can. Mobile-first with on-screen controls; keyboard, drag, and touch all supported.

Controls

  • Desktop: arrow keys or A/D to move, Space to shoot, P to pause, M to mute
  • Mobile: on-screen Left / Right buttons and Fire; drag anywhere on the canvas to steer

Open Ship Battle Source

Status: experiment on labs.inpriv.xyz/ship-battle.html — static asset, no backend, no telemetry, no accounts.

swift

native tool

Ultra-fast Rust text viewer for massive files

Inpriv Swift is a native desktop text editor engineered for opening and navigating files that crash conventional editors — log files, data exports, large codebases. It uses memory-mapped I/O (memmap2) and SIMD-accelerated line scanning (memchr) for instant performance on multi-gigabyte files. Built with eframe/egui for 60fps rendering and a minimal memory footprint — only visible lines are rendered.

Highlights

  • Zero-copy I/O — memory-mapped file reading, no full-file load into RAM
  • SIMD line scanning — memchr at memory bandwidth speed
  • Optional edit mode (Ctrl+E) — line-granular overlay, never copies the file
  • Read-only by default; saves only when explicitly requested
  • Fully offline, no telemetry, no network access

Source Docs

Status: native binary only — no web build. Build locally with cargo build --release from the repo.
