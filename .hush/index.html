Legal & Architecture

Zero-Knowledge Architecture

hush utilizes end-to-end encryption with ephemeral key exchange.

  • Forward Secrecy: Each DM message derives a unique key from an ephemeral X25519 keypair.
  • Key Pinning: Public keys are pinned on first use (TOFU) to prevent MITM attacks.
  • Metadata Shield: Link previews extract domain names locally without external API calls.
  • Ephemeral History: Room encryption keys are never sent to the relay server.
