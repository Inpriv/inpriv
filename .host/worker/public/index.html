Privacy Shield

How Inpriv Host protects you and everyone who visits your pages.

block

IP logger & tracker blocking

Before an HTML/text file is published, it is scanned for IP grabbers (iplogger.org, grabify, yip.su and 60+ more domains), hidden pixel beacons, and known tracking scripts. Anything found — the file is rejected. Nothing is served unverified.

podcasts

WebRTC leak neutralized

Served pages run inside a strict sandbox: no plugins, no same-origin access, no embedding. The sandbox headers plus our CSP strip the browser features a WebRTC leak needs, so visitor IPs cannot be harvested through your pages.

hide_source

Stealth headers on every response

Referrer, origin and cache data are stripped. Visitors of your pages do not leak the page they came from, and the platform adds no identifiers of its own.

vpn_key_off

Owner IP never stored

Uploads and management actions are processed without writing your IP address or user agent to any log. The database keeps only what the file list needs: name, size, timestamps and Drive file id.

shield_lock

Encrypted transport, everywhere

TLS 1.3 in transit, AES-256 at rest on Google's storage layer, and a strict CSP on the dashboard itself. Secrets live in Cloudflare's encrypted secret store — never in the code repository.

verified

Every upload verified

A scan record is attached to each file. If a scan fails, the file is quarantined and never reaches the public route. You see the exact finding and line number, so you can fix and re-upload.
