What we do: This tool queries several public DNS-over-HTTPS (DoH) JSON resolvers — Cloudflare and Google — directly from your browser and resolves their egress IP, then geolocates it. It also resolves a random test hostname through your browser's normal path and fetches your HTTP egress IP, then compares the two.

The honest limitation: A true DNS-leak test (like dnsleaktest.com) logs the source IP of your recursive resolver at an authoritative nameserver it controls. A pure web page cannot do that — the browser resolves names via the OS resolver (or its own DoH), which the page cannot observe, and cached entries produce no outbound query at all. So this tool is an approximation: it shows whether your DNS egress matches your HTTP egress and flags obvious mismatches, but it is not an authoritative resolver-log test.

If you use a VPN: a mismatch between your HTTP IP and your DNS egress can indicate DNS traffic escaping the tunnel. All checks here run client-side; no resolver logs your visit for this test.
